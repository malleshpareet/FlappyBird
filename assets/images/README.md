# Game Assets

Place the following image files in this directory:

## Required Assets:
- `bird.png` - Sprite for the bird character (recommended size: 32x32 pixels)
- `pipe.png` - Sprite for the pipe obstacles (recommended size: 64x400 pixels)
- `background.png` - Background image (recommended size: 288x512 pixels or larger)

## Optional Assets:
- You can use simple colored rectangles if you don't have image files
- The game will work with placeholder colors if assets are missing

## Asset Guidelines:
- Use PNG format with transparency
- Keep file sizes reasonable for mobile performance
- Bird should face right for proper animation direction
